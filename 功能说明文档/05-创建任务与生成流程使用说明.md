# 创建任务与生成流程使用说明

创建任务页已经重新整理为以 Collection 为入口的生成流程。

## 基本流程

1. 选择 Collection。
2. 填写任务基础信息。
3. 选择标题库、Master Prompt、可选 Skill Prompt、可选 Style Prompt、生成策略和模型。
4. 选择 Entity 和 Case。
5. 按需展开受控分组标签进行筛选。
6. 配置知识库、图片和发布方式。
7. 创建任务并生成文章。
8. 在文章详情页查看生成来源和质量检查。

## 任务回收站

任务列表页顶部提供“任务回收站”入口。

删除任务时，系统不会删除这个任务已经生成的文章，也不会清空文章和任务之间的来源关系。

删除后的任务会进入任务回收站：

- 文章列表和文章编辑页仍能看到来源任务名称。
- 如果来源任务已删除，会显示“已删除任务”标识。
- 回收站中的任务可以恢复。
- 恢复后的任务默认保持暂停状态，不会自动继续生成文章。

适用场景：

- 某个任务配置已经不用了，但保留它生成过的文章。
- 需要清理任务列表，又不想破坏文章来源追踪。
- 误删任务后，需要恢复任务配置继续查看或调整。

## Collection 必选

Collection 是创建任务的必选项。

它用于限定本次任务属于哪个业务容器，避免生成流程跨行业、跨业务线误用素材。

选择 Collection 后，Entity 和 Case 选择器会自动限制为当前 Collection 下的内容。

如果确实需要跨 Collection 引用，需勾选“允许跨 Collection 引用”。否则，后端提交时也会拒绝不属于当前 Collection 的 Entity 或 Case。

选择 Collection 后，Entity 和 Case 区域会直接显示当前可选数量。出现“暂无可选”时，可以不选择并继续创建任务；只有确实需要跨业务线引用时才开启跨 Collection。

## 页面顶部流程摘要

创建任务页顶部会同步显示四项状态：

- 业务上下文：当前选择的 Collection。
- 内容生成：还有多少个核心必填项未完成。
- 审核：生成后人工审核，或生成后自动通过。
- 发布范围：仅本站、仅渠道，或本站与渠道同时发布。

该摘要只用于提示当前配置，不新增数据库字段，也不会改变已经保存的任务。

## Entity 和 Case 选择

Entity 和 Case 支持多选 chip 样式。

推荐原则：

- 选择 1 到 3 个核心 Entity。
- 只选择与文章主题强相关的 Case。
- 不要一次选择过多 Entity，避免上下文发散。

## 受控分组标签

受控分组标签默认以折叠区域展示。

它是可选辅助筛选项，适合进一步限定 Topic、Audience、Intent 等轻量属性。

如果已通过 Collection 和 Entity 精准限定素材，可以不选择受控分组标签。

## Master Prompt、Skill Prompt 和 Style Prompt

内容配置区包含三个提示词入口：

- 内容提示词：必选，也就是 Master Prompt，负责事实、证据、隐私、安全和通用质量边界。
- Skill Prompt：可选，用于叠加某类文章的专属推理策略，例如对比、选型、应用、技术解释或排障；它不会强制所有文章使用同一套章节。
- Style Prompt：可选，用于手动指定写作语气、句式和表达偏好，例如决策支持、成本与价值、平衡对比、风险说明或步骤指南。

创建任务页默认使用“智能推荐 Skill Prompt”。

智能推荐会根据标题库名称和标题样本判断文章更像哪种结构，例如：

- comparison：对比、差异、vs、替代方案。
- buying guide：如何选择、选型、尺寸、购买指南。
- application：应用场景、行业、制造流程、use case。

如果匹配到对应 Skill，系统会在下拉框下方显示推荐 Skill、置信度、命中示例和原因。

选择“不使用 Skill Prompt”时，生成流程保持原来的 Master Prompt 单独生成方式。

选择 Skill Prompt 和 Style Prompt 后，系统会按以下顺序组合：

1. Master Prompt
2. Skill Prompt
3. Writing Style Prompt

然后再注入标题、关键词和 RAG 检索出的 `{{Knowledge}}`。文章结构应服从当前标题、证据和读者问题，不再默认强制 FAQ、表格、Key Takeaways 或 Conclusion。

注意：

Skill Prompt 不承担 Collection、Entity、Tag 或知识库分类职责，它只影响文章写法和结构。

Style Prompt 只控制表达方式，不承担素材筛选、事实判断、语言判断或文章结构职责。系统不会根据 URL 自动提取风格，也不会自动识别标题风格，更不会仿写具体作者。

智能推荐只是兜底，人工选择优先级最高。如果你已经按标题库手动分类，也可以直接选择对应 Skill；如果推荐不合适，手动改掉即可。

Style Prompt 没有智能推荐，必须由用户手动选择；默认“不使用 Style Prompt”。

创建新任务时，Skill Prompt、Style Prompt 和模型选择模式默认收在“高级生成设置”中。通常保持默认即可：系统智能匹配 Skill、不使用额外 Style，并固定使用当前主模型。只有需要人工覆盖文章结构、写作风格或启用模型故障切换时再展开。

## 标准生成和深度生成

“生成策略”位于高级生成设置中，提供两个选项：

- 标准生成：默认选项。使用现有单轮正文生成流程，速度快、模型调用少，适合普通草稿和快速迭代。
- 深度生成：质量优先。先策划文章，再生成正文和执行审核；首次审核不通过时最多局部修正一次，因此耗时和 Token 通常更高。

深度生成的内部顺序是：

1. 只执行一次 RAG 检索并冻结本次证据。
2. 生成结构化策划，明确读者问题、回答模式、可写章节、证据映射和起草前待确认项。
3. 根据策划和原始证据生成完整正文。
4. 审核事实支持、清晰度、决策价值、结构自然度、负面适用边界、隐私、安全、Style 遵循度和模板感。
5. 只有未达标时才进行一次局部修正和最终审核。

策划阶段还会判断本次证据是否足够：

- 证据充足：按正常深度流程生成。
- 证据有限：允许生成更短、范围更窄的文章，不会为了目标字数或固定章节补写没有依据的内容；草稿一定进入人工审核。
- 证据有限的文章还会经过程序化防扩写检查，明显超出冻结证据范围时会直接阻断，而不是只依赖提示词提醒。
- 证据不足：在策划阶段停止，不生成正文；任务页只显示受控的待补资料分类。该结果不能通过手动修改审核状态直接发布，必须补充资料后重新生成。

因此，深度生成的目标不是保证每个标题都产出长文，而是优先保证文章没有超出实际素材边界。

任务列表会把最近一次生成结果显示为六种受控状态：

- 草稿可用：文章已生成并通过当前自动审核，可进入文章页继续人工确认或发布。
- 需要人工审核：文章已保存，但证据有限、审核未完全通过，或属于必须人工检查的内容类型。
- 证据不足：没有生成正文；补充知识库、Entity、Case 或其他必要资料后重新执行。
- 生成协议异常：模型连续两次没有返回符合结构协议的策划；不会自动重试，可检查模型兼容性或更换模型。
- 内容已被安全门禁拦截：正文包含无证据主张、无效引用、受限内容或阻断级隐私/安全问题；不会自动重试，应先修正素材、标题或生成要求。
- 模型服务异常：模型不可用、超时、鉴权失败或调用预算耗尽；系统先按任务队列预算重试，预算耗尽后才显示为最终失败。

这些状态只展示安全摘要，不会在任务列表暴露原始 Prompt、策划 JSON、知识库正文、客户资料或 API 密钥。

使用建议：

- 一般文章先用标准生成。
- 高价值产品、对比、采购决策或需要更严格证据约束的文章使用深度生成。
- 深度审核仍不通过时，文章会保存为“待审核”草稿，不会自动发布。
- Case Study 和 Troubleshooting 即使审核分较高，也继续要求人工审核。
- 写作风格仍可留空；选择深度生成并不要求必须选择 Style。

## AI 模型选择

创建文章任务时的 AI 模型用于正文生成。

它和 URL 智能采集任务中的 AI 分析模型不是同一个入口：

- URL 采集模型：用于网页清洗、知识库整理、关键词和标题生成。
- 文章任务模型：用于根据标题、关键词、RAG 上下文和提示词生成正文。

如果 URL 采集结果质量不好，可以在 URL 采集创建页切换采集模型重新测试。

如果文章正文质量不好，应在创建任务页切换文章生成模型，或调整 Master Prompt / Skill Prompt。

后台 AI 模型配置页还可以为聊天模型设置“正文最大输出 Token”。

这个配置只影响文章正文生成，不影响 URL 智能采集、知识库切片或素材 AI 分析。

使用建议：

- 生成长篇文章经常被截断时，提高该聊天模型的正文最大输出 Token。
- 不确定模型支持上限时，先留空使用系统默认值。
- 如果某个服务商报参数错误，优先检查该服务商是否支持当前模型和 token 上限。

## 图片配置

图片配置区支持：

- 不指定图库：默认选项，系统仍可从可用图片中自动匹配。
- 选择关联图库：优先选择与所选 Entity 相关的图库或图片。
- 不配图：在配图数量中选择，表示明确关闭图片。
- 自动匹配：系统根据文章结构和素材规则选择合适数量。
- 固定数量：按指定数量配图。

注意：

“不指定图库”和“不配图”不是一回事。

- 不指定图库：仍允许系统配图。
- 不配图：完全不使用图片。

## 发布配置

新建任务采用安全默认值：

- 默认勾选“需要人工审核后才能发布”。
- 默认发布范围为“仅发布到本站”。
- 关闭审核或选择远程渠道后，页面会显示风险提示。

这些默认值只影响新建任务。编辑已有任务时会继续使用该任务原来的审核与发布设置。

文章列表中新增发布入口后，可对已生成文章单独发起发布。

发布时会弹出确认框，显示可选发布渠道。确认后文章进入发布队列并执行发布流程。

## 生成后的检查

生成完成后建议检查：

- 生成来源是否包含预期 Entity、Case 和知识库。
- 生成模式、Style 和深度阶段是否符合本次任务配置。
- 深度审核是否通过，是否存在待人工处理的问题代码。
- 质量评分是否偏低。
- 是否缺少 FAQ、图片或关键词覆盖。
- 是否使用了错误 Collection 或错误素材。
